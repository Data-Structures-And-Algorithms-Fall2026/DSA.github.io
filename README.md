# کلاس درس ساختمان داده و الگوریتم‌ها

سایت دوره ساختمان داده و الگوریتم‌ها — سال تحصیلی ۱۴۰۵ · استاد دوره: دکتر قربانعلی

## بخش‌ها

- **رودمپ کلاس** — تخته وایت‌بردی افقی با موج سینوسی، از هفته ۰ تا ۱۳
- **رودمپ تدریسیاری** — تایم‌لاین عمودی از بالای صفحه به پایین (جلسات + آزمون‌ها + ریلیز تمرین‌ها)
- **تمرین‌ها** — ۶ سری (لینک‌ها در `js/data.js` → `EXERCISES`)
- **کارگاه‌ها** — ۴ کارگاه (لینک‌ها در `js/data.js` → `WORKSHOPS`)
- **کارگاه‌های ویژه** — دکمه «به‌زودی»
- **ارتباط با تدریسیاران** — ۴ کارت (مشخصات در `js/data.js` → `TUTORS`)

## اجرا

استاتیک و بدون build:

```bash
python3 -m http.server 8080
# یا از خود پوشه با GitHub Pages
```

## تنظیمات سریع

| چه چیزی | کجا |
|---|---|
| لینک تمرین‌ها / کارگاه‌ها | `js/data.js` → `EXERCISES.link`, `WORKSHOPS.link` |
| مشخصات تدریسیاران | `js/data.js` → `TUTORS` |
| عنوان / جلسات هر هفته | `js/data.js` → `CLASS_ROADMAP`, `TUTORING_ROADMAP` |
| رنگ‌ها و تم | `css/styles.css` → بلاک‌های `:root` و `html[data-theme=...]` |
| نقاشی‌های SVG هر مبحث | `js/illustrations.js` |

## GitHub Pages

1. این پوشه را به یک ریپازیتوری (مثلاً `ds-course-ui`) push کنید
2. Settings → Pages → Source: `main` / `(root)`
3. فایل `.nojekyll` از قبل موجود است (فایل‌های `.`/`_` حذف نمی‌شوند)
